Diseña y audita con IA: skills para Claude

Cada skill se instala una vez y le da a la IA un método de UX. Si nunca instalaste una, sigue la guía de instalación paso a paso.

  • Skill para Claude

    Auditoría UX con IA

    Audita cualquier producto web y obtén un informe con hallazgos fundamentados.

    Diez skills que revisan usabilidad, accesibilidad, contenido, jerarquía, navegación, estados y formularios.

    Obtener la skill
  • Skill para Claude

    Diseño guiado con IA

    Pasa de la idea al prototipo navegable con pantallas que alguien pensó.

    Siete skills que guían a la IA paso a paso, en lugar de un «diséñame una app».

    Obtener la skill
  • Skill para Claude

    Excalidraw UX

    Pide un flujo, un wireframe o un mapa y recibe un diagrama que puedes editar.

    Diagramas de UX con estilo hecho a mano, en archivo de Excalidraw o en imagen.

    Obtener la skill
  • Skill para Claude

    Crea tu asesor

    Consulta a un experto de UX que responde citando sus fuentes.

    Incluye un ejemplo armado con la obra de Jakob Nielsen.

    Obtener la skill
  • Skill para Claude

    Modo riguroso

    Haz que la IA compruebe antes de afirmar.

    Para cuando la respuesta suena segura y después resulta que estaba mal.

    Obtener la skill
  • Skill para Claude

    Ahorro de tokens

    Termina tu trabajo sin quedarte sin límite de uso a la mitad.

    La IA responde al grano y gasta menos en cada conversación.
